# Parallel Computing Exercises

This repository contains several parallel programming exercises implemented using **OpenMP** and **MPI**.

The programs include examples such as:

- numerical integration
- prime number computation
- image filtering
- Newton fractals
- comet simulations
- matrix–vector operations
- linear system solvers

## Note

The base code for these programs was provided as part of university assignments.

My work focuses on implementing the **parallelization of the algorithms**, including:

- adding OpenMP directives
- implementing MPI communication patterns
- distributing data among processes
- handling synchronization and reductions

The goal of these exercises is to explore different parallel programming techniques and evaluate their performance.
